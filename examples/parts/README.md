# 020の交換部品と検証作品

このディレクトリはカスタム部品の編集元です。
家やケーキの種類は本体のコードへ登録せず、共通の部品ファイルとして定義しています。
アプリの初期ライブラリには入りません。

| ディレクトリ | 内容 | 入力の最大開口角 |
| --- | --- | --- |
| `house` | 屋根形に切り抜いた縦置き面。背景と地面から支持する | 90° |
| `cake` | 画像と天板色を公開した四面の折り畳み箱。両端は開いている | 180° |
| `box-150` | 最大開口角による配置拒否を確認する箱 | 150° |

## 作成と読み込み

```powershell
npm run build
node scripts/generate-part-examples.mjs
```

既定の出力先は `.tmp/020-preview/` です。
スクリプトの第一引数で別の出力先を指定できます。
生成時は本体と同じスキーマ、部品評価器、素材のハッシュ処理、絵本の検証・書き出し処理を通します。

部品エディターの「読み込み」で `house.tobidas-part.zip` などを選びます。
または「フォルダーを読み込み」で、このディレクトリの `house` などを選びます。
「ライブラリに保存」後、絵本編集のカスタム部品から配置できます。
家を置くときは、先に基本部品の背景パネルを本の谷へ配置し、「背景パネル / 地面と背景」を接続先に選びます。

生成した `020-connected-parts/` は編集用の作品フォルダーです。
`020-connected-parts.html` は素材とプレイヤーを同梱した再生用HTMLです。
生成先の `tobidas-part-v1.schema.json` が交換形式のJSON Schemaです。
実行時の検証は `src/parts/schema.ts` と `src/parts/validate.ts` を正本とします。

## 検証作品

1. 本の谷から背景、支持ブリッジ、二軒の家へ接続をつなぐ。
2. 180°まで開く本の谷でケーキの箱を開く。
3. 同じ箱を90°まで開く背景の接続口へ置き、途中姿勢で止める。
4. 一つ目の看板が公開する面から、次の看板を支える。

150°の箱は180°の本の谷に配置できません。
現在の表示角が150°以下であっても、接続先の開閉経路全体で判定します。
実際の角度を基準開口角へ引き伸ばす処理はありません。

## 編集と改訂

公開する寸法・素材・接続口は `part.json` へ保存します。
輪郭は面の幅と高さに対する0〜1の材料座標です。
接着辺と支持材を除去する形状は検査で拒否します。
部品名、説明、作者、配布条件、素材も外部ファイルに含めます。

共有用ZIPには必要な依存定義と素材を同梱し、内容ハッシュで照合します。
絵本への配置時にも定義と素材をコピーするので、元のライブラリがなくても再生できます。
新しい改訂は既存の配置へ自動反映されません。

## 検査の範囲

紙面は剛体、ヒンジは厚みゼロとして評価します。
入力角度の端点と途中姿勢で、接着辺、面の寸法、収納範囲を確認します。
角度の有限サンプル検査は、紙の厚みを含む連続的な衝突判定ではありません。
生成結果の `verification.json` は構造検査の記録です。
構図、重なり、ページ送り中の見え方は、再生画面でも確認します。

素材のSVGはこの交換例のために作成したもので、リポジトリのApache-2.0ライセンスで配布します。
